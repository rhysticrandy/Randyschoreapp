# My Chore Reset
A phone-friendly chore/routine web app.

## Use on iPhone
1. Put these files on a web host (GitHub Pages, Netlify, Vercel, etc.).
2. Open the site's `index.html` URL in Safari.
3. Share -> Add to Home Screen.
4. Open the app from the Home Screen.
5. Use Settings to choose reminder times and enable notifications.

Check-offs are stored locally on the device.

Note: browser/iOS notification behavior depends on how the app is hosted and installed. The app itself does not send cloud/server notifications.
